# Game Design for Myanmar

A 2D survival game built in Unity and C# to raise awareness of Myanmar's
2021 military coup, developed through Bridgewater State University's
Adrian Tinsley Program (ATP) summer research program under faculty
mentorship (Dr. Paul Kim).

The game simulates the experience of peaceful protesters, using character
animation, player movement scripting, and a narrative dialogue system to
put players in a protester's position during the crisis.

Tools: Unity, C#, Krita (2D sprite creation)

Full research poster (methods, results, references) is included in this repo.
